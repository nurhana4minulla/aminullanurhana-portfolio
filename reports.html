Activities & Assignments

This week began with finalizing the necessary bug fixes and testing for the previous modules. While awaiting further instructions, my supervisor, Ma'am Sharon, assigned me a new major task: developing a generative printable feature for employee "Certifications."

I was provided with an official MS Word document template as a reference. My primary responsibility was to transition this manual template into a fully automated PDF using the FPDF PHP library. I built a dynamic text-generation script that automatically adjusts pronouns based on the employee's sex, formats employment dates, and intelligently hides or displays department information depending on whether the employee is a Job Order (JO) or Contract of Service (COS) worker.

Accomplishments & Achievements

I successfully finalized the pending system fixes from the previous week, ensuring the core modules were completely stable.

Following the new requirements, I developed and integrated the generate_certificate.php module, which instantly produces a ready-to-print, official Employment Certification for any worker in the database. To achieve this, I programmed a custom PHP class (class PDF extends FPDF) to automatically stamp the official DTI Region IX header and footer images onto every generated document.

Challenges & Problem Solving

A significant technical challenge involved FPDF's text formatting limitations. The official document required paragraphs to be both perfectly Justified and contain inline bold text (specifically for the employee's name). However, FPDF's MultiCell() function only supports Justification with a single font style, while the Write() function supports inline bolding but cannot justify text.

To resolve this, I prioritized the professional Justified margins using MultiCell(). Since the system already formats the employee's name in ALL CAPS, I utilized this capitalization to make the name naturally stand out within the standard paragraph, fulfilling the visual requirement without breaking the official margin alignment.

Skills Applied

  • Backend PHP (OOP): Extended the base FPDF class to create a custom PDF object that automatically handles the repetitive placement of headers/footers.
  • Algorithm Design: Wrote dynamic logic to evaluate employment types and automatically adjust the legal wording of paragraphs.
  • Problem Solving: Solved typography limitations by calculating the exact millimeter offset needed to replicate standard 12pt paragraph spacing ($space_12pt = 4.23;).

Learning Outcomes

  • Technical: Learned to extend object-oriented PHP classes for custom PDF behaviors and mathematically convert word processor typography (Points/Centimeters) into backend code formats.
  • Professional: Demonstrated adaptability by transitioning from bug fixing to analyzing a client-provided template and translating business rules into dynamic logic.
